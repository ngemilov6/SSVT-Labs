Time spent: 75min
Design Report:
The current implementation identifies the smallest subsets of multiplication-table properties that kill exactly the same generated mutants as the complete property set. 
A property subset is considered effective when, for every generated mutant, the subset kills the mutant if and only if at least one property in the full set kills it.
generateMutationResults produces the Boolean outcomes of all properties for one non-equivalent mutant. 
It randomly selects a mutator and input value, applies the mutation process, and regenerates the result when the mutation is equivalent. 
This ensures that the subsequent analysis only considers mutants for which property outcomes are available.
killsMutant determines whether a selected subset kills a mutant. A mutant is killed when at least one selected property returns False. 
fullSetKillsMutant applies the same criterion to the complete property set. 
In minimalPropertySubsets, all subsequences of the property indices are evaluated against every generated mutation result. 
Subsets whose kill behaviour matches that of the full set are retained as effective subsets.
The implementation calculates both inclusion-minimal and smallest-cardinality candidates. 
strictSubsetOf and minimalIndexSubsets identify subsets for which no strictly smaller effective subset exists. 
However, the returned result is smallestIndexSubsets: all effective subsets with the minimum number of properties. 
This means the final output reports the globally smallest property subsets, rather than every inclusion-minimal subset.
The main function applies this analysis to the multiplication-table properties, maps property indices to readable names, and prints the number, contents, and sizes of the returned subsets.
A crucial insight from this exercise is the difference that the number of mutants has on the outcome.
For a small sample size of 4000 mutants, there are multiple smallest subsets ({1,n} for all n=2,3,4,5) while for 1'000'000 (which already takes ~10 seconds to run), 
the smallest subset is consistently only {1,4}. This means that for the other ones, there is sometimes no counter example generated if the sample size is too small.
That being said, even for {1,4}, from this analysis alone, we cannot be certain that it is a proper minimal subset of properties, which may lead to a 3-property minimal subset instead,
if a counter example for {1,4} is found.
