Exercise 3
Time spent: 40 minutes

Design Report:
The current implementation calculates the minimal property subsets as a purely functional 
mathematical operation. The function minimalSubsets takes a list of properties, a list of 
mutants, and an evaluation function (killsFunc) to compute the result. It generates all 
possible property combinations using subsequences, identifies which subsets kill the exact 
same maximum number of mutants as the full suite, and finally isolates the subsets with the 
minimum length. This perfectly models the theoretical definition of a minimal subset required 
for mutation testing without introducing unnecessary execution overhead.

Alternative Implementation Analysis:
During the code merge process, we reviewed an alternative implementation. This alternative 
embedded QuickCheck IO execution directly into the subset calculation. It utilized a custom helper 
function (properSubsetOf) alongside a complex list comprehension to manually filter out larger 
subsets. Most notably, its internal evaluation logic (subsetSatisfies) ran the properties strictly 
against the original, unmutated output of the function under test, rather than applying them to 
generated mutants.

Rationale for Final Selection:
We chose to proceed with the shorter, functional implementation for three primary reasons:
- Correctness: In mutation testing, a minimal property subset is strictly defined by its ability
to maintain the maximum mutant kill rate, not just its ability to pass against valid inputs. The 
alternative implementation did not test against mutants, meaning it missed the core objective of 
the exercise. 
- Separation of Concerns: By keeping the calculation as a pure function, we avoid bloating the 
file with complex IO sequencing. The actual QuickCheck test executions are cleanly delegated to 
Exercise 6, leading to a much more modular codebase.
- Simplicity: The chosen solution is significantly more concise because it leverages standard 
Haskell list operations (grouping by length and using minimum) instead of writing manual recursive 
subset filters and custom IO runner configurations.
