Design Report:
The powerSet function is implemented recursively, establishing a base case
where an empty list returns a list containing the empty set. For the recursive
step, the function generates subsets by appending the head element to each
existing subset of the tail using map(). To verify this implementation, four
distinct QuickCheck properties were designed to evaluate the formal powerset
specifications. The properties prop_powerSetCardinality and prop_powerSetCardinality_1_to_n
test the cardinality theorem, verifying that the number of elements in the generated 
powerset always equals 2^n. The latter explicitly tests integer lists of the form [1..n] 
to satisfy the precise assignment requirements. Additionally, prop_powerSetNoDuplicates 
verifies that the powerset of a distinct set is itself composed of distinct subsets, 
utilizing nub to ensure the length remains unchanged after duplicate removal. Finally, 
prop_powerSetSoundness guarantees the actual content is mathematically valid by checking 
that every generated subset is a true subsequence of the original input.   

Test Report and Questions:
The testing suite carefully limits input sizes through custom generators like sublistOf 
and resize 10 to avoid extreme resource consumption. Addressing the first question posed 
by the assignment, the cardinality property is exceptionally difficult to test for larger 
inputs due to the exponential growth of powersets. Generating a powerset for a list of just 
20 elements requires producing over a million subsets, making it highly computationally 
and memory-intensive. Regarding the second assignment question, these tests are not evaluating 
the underlying mathematical fact itself, as the cardinality property can already be proven 
mathematically via induction. Instead, we are testing whether our specific programmatic 
implementation satisfies its formal specification across a sampled domain. While randomized 
testing on an infinite domain cannot guarantee absolute correctness for all possible inputs, 
covering these varied properties provides high confidence that the implementation correctly 
handles the required behaviors and edge cases.
