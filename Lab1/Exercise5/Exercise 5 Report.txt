Design Report:
The isDerangement function evaluates two core properties: whether the lists 
are permutations of each other (reusing the verified implementation from Exercise 4)
and whether any elements at the same index share the same value (implemented using 
zipWith (/=)). The deran function generates the required output by filtering the 
exhaustive list of permutations through this isDerangement predicate. A base case 
safely returns an empty list, while negative inputs intentionally throw an error, 
explicitly restricting the operational domain to positive integers of the form 
[0..(n-1)] for n>0.   

Test Report and Property Strength: 
To automate the testing process,the custom unique-element generators from Exercise 4 
(gen_perms, gen_perm, genList, and makePerm) were adapted to produce permutations 
strictly bounded by [0..(n-1)]. The test suite employs three QuickCheck properties. 
The first, prop_deran_valid, independently verifies that every list generated by deran 
successfully passes the isDerangement check. The remaining two evaluate isDerangement itself: 
prop_derangement_symmetric checks for relational symmetry, while prop_derangement_no_fixed_points
verifies the absence of equivalent values at identical indices. These properties are tested
against both the automated generators and a curated set of well-chosen manual test cases
that effectively cover edge cases like identical lists, singletons, varying lengths, and
sets with duplicates. Addressing the assignment's requirement to order properties by 
strength, the symmetry property and the no-fixed-points property are strictly incomparable.
Confirming a relation is symmetrical does not mathematically imply the absence of fixed points, 
nor does the absence of fixed points imply symmetry; therefore, neither is stronger or 
weaker than the other. Because all automated and manual QuickCheck runs passed with zero 
discarded tests, we confidently conclude that the implementation satisfies these formal 
properties within the sampled domain, while acknowledging the standard limitation that 
randomized testing cannot exhaustively cover the infinite input space.
